# Как это устроено внутри

## Мост

OpenMW на Windows запрещает Lua доступ к файлам, поэтому обычный обмен через
файлы не годится. Мост обходит это так:

- **игра → мост**: Lua печатает `print('[MWAI_REQ] {json}')`, строка попадает
  в `openmw.log`, мост его читает;
- **мост → игра**: ответ пишется в `openmw-mod/ai_inbox/response.txt`, Lua
  читает его через виртуальную файловую систему.

**Главное правило, на котором мы обожглись:** VFS отдаёт скрипту тот размер
файла, который был при **запуске игры**. Поэтому все файлы обмена — постоянного
размера (16384 байта для ответов, 256 для настроек), дописываются подгонкой
пробелами и подменяются целиком. Файл, созданный после старта игры, скрипт не
увидит вовсе.

## Из чего состоит

```
openmw-mod/scripts/
  dialogue_ui.lua          окно, клавиши, действия, сцены, судьбы (~3300 строк)
  disposition_service.lua  глобальные действия: переселение, вещи, преступления
python/
  openmw_log_bridge.py     мост: чтение лога, очередь ответов, слоты
  agents/lore_agent.py     диалог: промпт, разбор тегов, память
  agents/scene_agent.py    сцены на несколько человек
  world_tuning.py          ручки характера мира
  stt_daemon.py            распознавание речи (Vosk)
  tts_*.py                 четыре движка озвучки
tests/                     107 тестов + живые проверки
```

## Формат ответа модели

Реплика идёт **первой**, теги — после неё. Это не случайно: текст можно
показывать по мере набора, а мир менять только по готовым тегам.

```
<npc_response>
Иди прямо по мосткам, там будет таможня.
</npc_response>
EMOTION:neutral
ACTION:none
TARGET:none
DISP:+1
...
```

Разбор **защитный**: неизвестный тег превращается в `none`, выдуманное имя
выбрасывается, служебные строки не попадают ни на экран, ни в озвучку. Модели
изобретательны — в живых прогонах встречались `LOAN=no` вместо `LOAN:no`,
`<Tidral's Response>` вместо нашего маркера и целые теги кириллицей.

## Тесты

```
venv\Scripts\python.exe tests\test_all.py
```

107 штук, все без запущенной игры. Отдельно живые проверки, расходующие
запросы к модели:

| Файл | Что проверяет |
|---|---|
| `e2e_live.py` | сквозная цепочка через настоящий мост |
| `scene_live.py` | сцены: состав, действия, защита квестовых |
| `fates_live.py` | судьбы, включая зацикленную |
| `latency_live.py` | задержку по звеньям |
| `tuning_live.py` | что делают ручки |
| `stt_shootout.py` | очная ставка движков распознавания |

## Правила, выведенные болью

- **У Lua предел в 200 локальных переменных на файл.** Превысив его, скрипт не
  компилируется целиком, и игра остаётся без всех клавиш. Держим потолок 195,
  проверяется тестом.
- **`duration` у пакетов ИИ считается в ИГРОВЫХ ЧАСАХ.** Значение 7200 — это
  триста суток, а не два часа. Персонаж замирал навсегда.
- **Действия из разговора отсчитываются ОТ ИГРОКА.** В сцене посторонних
  `callguards` заявлял на игрока, `attack` без цели бил игрока. Поэтому набор
  действий сцены урезан до трёх.
- **Белые списки должны совпадать в трёх местах** — промпт, разбор, Lua. Иначе
  модель послушно ставит тег, а он молча пропадает.

Каждая такая история записана в [ЖИВОСТЬ-ЖУРНАЛ.md](../ЖИВОСТЬ-ЖУРНАЛ.md) с
тем, чем именно она была проверена.
