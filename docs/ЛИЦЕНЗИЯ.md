# Лицензия по-русски

[LICENSE](../LICENSE).


Делайте с этим кодом что хотите: пользуйтесь, меняйте, раздавайте, вставляйте
в свои проекты, в том числе платные. Единственное условие — сохраняйте этот
файл с указанием авторов. Гарантий никаких: если что-то сломается, спросить
будет не с кого.

## Что НЕ покрыто лицензией и не входит в репозиторий

  • Сама игра The Elder Scrolls III: Morrowind и всё её содержимое —
    собственность Bethesda Softworks. Купите игру.
  • Озвучка из игры и голосовые модели, обученные на ней. В репозиторий они
    не входят: их собирают локально из вашей собственной копии игры
    (см. docs/ГОЛОСА.md).
  • Движок OpenMW — отдельный проект под GPLv3, ставится отдельно.
  • Модели распознавания речи Vosk — Apache 2.0, скачиваются установщиком.
  • Голоса Piper — MIT, скачиваются установщиком.
  • Ответы облачных моделей — по условиям их поставщика.
